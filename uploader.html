Kilbane Channel Uploader

A private desktop tool. Last updated October 21, 2026.

Kilbane Channel Uploader is a small desktop application that Jim Kilbane uses to upload and schedule his own finished videos on his own YouTube channels. It uses YouTube API Services (the YouTube Data API v3 and the YouTube Analytics API).

Who uses it

Only Jim Kilbane. The app is not offered to the public, is not sold, and has no other users. It signs in only to YouTube channels that Jim owns and manages:

  • Leonida Dossier
  • Cyber Heists
  • Mob Crimes
  • Mob Dynasties
  • Wired & Wanted
  • Tools & Tech
  • Shadow Archives
  • Failure Point
  • Paper Empires
  • Street to Studio

What it does with YouTube data

After Jim signs in with his Google Account and grants access, the app does only these things, and only on his own channels:

  • Uploads Jim's own finished videos as private, with a scheduled publish time.
  • Sets each video's custom thumbnail.
  • Declares altered or synthetic content where it applies. The narration on these channels is AI generated from Jim's own cloned voice, and the app marks that on each upload.
  • Sets an older video of Jim's own to private when a remade version replaces it.
  • Reads the channel's own list of videos so it does not schedule two videos into the same slot.
  • Reads the channel's own analytics so Jim can see how his videos perform.

What it never does

  • It has no third-party users and never accesses anyone else's account or channel.
  • It does not share, sell, rent or transfer any YouTube or Google data to anyone.
  • It does not post, read or moderate comments, and it does not like, rate or subscribe.
  • It does not show ads and has no advertising partners.

How sign-in and storage work

The app runs on Jim's own laptop. It signs in through Google's standard OAuth 2.0 flow for desktop apps, using a local loopback address on the laptop and PKCE. The access tokens it receives are stored only on that laptop. There is no app server, no cloud database and no account system of its own.

Access can be removed at any time from the Google Account permissions page at security.google.com/settings/security/permissions.

Kilbane Channel Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.
